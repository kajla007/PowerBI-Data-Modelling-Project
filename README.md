# Power BI Data Modelling Project

## 📌 Project Overview

This project focuses on transforming a complex collection of business tables into a structured and analysis-ready data model using Microsoft Power BI.

The model covers sales, customers, products, inventory, order processing, invoices, payments, shipments, and marketing campaigns.

## 🎯 Project Objectives

- Organize business data into fact and dimension tables.
- Establish relationships between related datasets.
- Keep the core data model structured around business requirements.
- Avoid unnecessary complexity and confusing relationships.
- Support integrated business analysis across multiple domains.

## 🗂️ Data Model Components

### Fact Tables
- `fact_sales`
- `fact_inventory`
- `fact_order_process`
- `fact_campaign`
- `fact_promotion_coverage`
- `fact_sales_target`

### Dimension Tables
- `dim_customer`
- `dim_product`
- `dim_geo`
- `dim_campaign`
- `dim_order_flags`

Additional customer contact data supports the model.
